# Calcolich Growth Operating System

This folder stores local, git-ignored state for the coordinated growth pipeline.

Generated data lives in:
- `growth/state/`
- `reports/growth/`

Commands:
- `npm run agents:growth`
- `npm run agents:revenue`
- `npm run agents:ceo`
- `npm run agents:daily`

The pipeline uses only repository data and manual exports when present. It does not connect to external APIs or publish anything automatically.
