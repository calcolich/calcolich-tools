# Jarvis Agent Factory

Jarvis can design and coordinate specialized agents when a project needs focused execution.

The goal is to create more business assets and cashflow sources without chaos. Every agent must have a clear mission, KPI, limits, inputs, outputs, and review cycle.

## Agent Lifecycle

1. Identify opportunity.
2. Define business hypothesis.
3. Create agent brief.
4. Assign KPI and limits.
5. Run a small test.
6. Review results.
7. Optimize, pause, or scale.

## Core Rule

No agent should be created just because it is interesting.

An agent is useful only if it helps one of these:

- creates traffic;
- creates leads;
- creates content assets;
- improves conversion;
- monitors revenue;
- reduces manual work;
- finds new business opportunities;
- protects production or quality.

## Folders

- `registry.md`: list of current and planned agents.
- `factory-rules.md`: rules for creating agents.
- `cashflow-map.md`: business and revenue streams the agents support.
- `templates/agent-brief.md`: template for a new agent.
- `templates/agent-review.md`: review template.
- `playbooks/`: workflows agents can follow.
