# Launch New Agent Playbook

Use this when Jarvis needs a new specialist agent.

## Steps

1. Define the business opportunity.
2. Confirm why Jarvis alone is not enough.
3. Write an agent brief.
4. Define the first 7-day test.
5. Define the KPI.
6. Define what the agent cannot do.
7. Add the agent to `registry.md`.
8. Run one small task.
9. Review output quality.
10. Continue, optimize, or stop.

## First 7-Day Test

Every new agent starts small:

- one project;
- one objective;
- one measurable output;
- one review.

No broad automation before the first review.
