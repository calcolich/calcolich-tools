# Operating Preferences

## Default Behavior

If the task is clear, act.

Ask only when:

- credentials are needed;
- payment or account actions are needed;
- a destructive action is ambiguous;
- the requested change could damage production or unrelated work.

## Code Work

- Keep changes conservative.
- Do not touch unrelated files.
- Do not overwrite user work.
- Commit messages in English.
- Verify before push.
