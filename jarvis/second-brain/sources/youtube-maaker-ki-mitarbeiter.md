# Source Note: Moritz Maaker - Dein bester Mitarbeiter ist ab jetzt eine KI

Source:

- YouTube: `https://www.youtube.com/watch?v=Od9fqgegYJU`
- Title: `Dein bester Mitarbeiter ist ab jetzt eine KI`
- Author: Moritz Maaker

## Relevant Idea

The video explains why a business cannot scale well when all context lives in the founder's head or in disconnected tools.

The useful concept for Jarvis:

- tools alone are not enough;
- the business needs one central second brain;
- the second brain must know customers, projects, offers, routines, and decisions;
- the system must communicate proactively;
- the system must also act, not only store notes;
- AI becomes useful when memory, tools, channels, and execution meet in one operating system.

## Translation Into Jarvis

Jarvis should become Giuseppe's AI operating employee:

- Brain: second brain, project memory, decisions, lessons, customer/business context.
- Hand: task creation, agent assignment, execution plans, VS Code tasks, deploy checks.
- Voice: browser voice, future Telegram, daily brief, direct status updates.
- Agents: specialist departments for SEO, content, monetization, QA, scouting, and trading.

## Implementation Rules

- Do not create disconnected tools.
- Every new tool must feed the second brain or execute a task.
- Every agent must have KPI, permissions, and stop condition.
- Voice commands must produce real tasks.
- Jarvis must reduce Giuseppe's manual context switching.

## Current Gap

The dashboard can create tasks, but the agents do not yet autonomously process the task lifecycle.

Next implementation should add:

- inbox processor;
- task status transitions;
- generated outbox reports;
- agent-specific execution templates;
- optional Telegram channel after local stability.
