# SEO Machine

## Calculator Page Formula

Every serious calculator page should have:

- unique SEO title;
- unique meta description;
- correct canonical;
- correct locale and hreflang;
- one clear H1;
- fast calculator above the fold;
- short intro;
- formula explanation;
- practical example;
- FAQ only if real questions exist;
- related calculators;
- internal links to support articles;
- appropriate schema;
- no duplicate or empty sections.

## Article Page Formula

Every support article should:

- target one clear long-tail topic;
- link to the relevant calculator early;
- include examples or rules;
- include 3-5 real FAQ;
- link to related calculators and articles;
- stay useful, not bloated.

## Search Console Workflow

Weekly:

1. Export queries and pages.
2. Group queries by calculator cluster.
3. Mark pages with impressions and low CTR.
4. Mark pages ranking 8-20.
5. Pick one page to improve.
6. Pick one new content opportunity.
7. Update `weekly-growth-review.md`.

## Optimization Rules

If a page has impressions but low CTR:

- improve title and meta description;
- make the benefit clearer;
- add Switzerland-specific wording when relevant.

If a page ranks 8-20:

- improve content depth;
- add internal links from stronger related pages;
- add FAQ if real questions are visible;
- check page speed and mobile layout.

If a query appears but no matching page exists:

- create a calculator brief first;
- check whether it belongs as a calculator or article;
- avoid creating a page until search intent is clear.
