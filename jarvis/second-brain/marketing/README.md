# Marketing Operating System

This folder turns Jarvis into a continuous growth assistant for Calcolich.

The goal is not random marketing. The goal is a repeatable system:

1. Find demand.
2. Create or improve the right calculator.
3. Support it with useful long-tail content.
4. Connect pages with internal links.
5. Measure results.
6. Improve pages that show early traction.
7. Add monetization only where it fits intent.

## Core Growth Loop

Every week Jarvis should run this loop:

1. Review Search Console data.
2. Find pages with impressions but low CTR.
3. Find pages ranking positions 8-20.
4. Find queries that deserve new calculator pages.
5. Improve one existing page before creating many new ones.
6. Add or strengthen internal links.
7. Update the experiment log.

## Main Files

- `strategy.md`: overall marketing strategy.
- `seo-machine.md`: SEO process for calculators and articles.
- `conversion-optimization.md`: how to turn traffic into value.
- `monetization-map.md`: when and how to monetize.
- `kpi-scorecard.md`: what to measure.
- `content-clusters.md`: topic clusters to build.
- `weekly-growth-review.md`: weekly review checklist.
- `experiment-backlog.md`: experiments to run.
