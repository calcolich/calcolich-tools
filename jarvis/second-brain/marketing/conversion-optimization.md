# Conversion Optimization

## Main Conversion Goals

Calcolich should convert useful traffic into value without damaging trust.

Primary conversion goals:

- saved result;
- PDF download;
- newsletter signup;
- relevant affiliate click;
- service lead;
- return visit.

## Placement Rules

Above the fold:

- calculator input and result;
- no heavy distractions.

After result:

- save result CTA;
- PDF CTA;
- related calculator links.

After explanation:

- newsletter or lead magnet;
- article links;
- relevant affiliate box only when useful.

## CTA Ideas

- Ergebnis speichern
- PDF herunterladen
- Berechnung per E-Mail senden
- Weitere Rechner anzeigen
- Checkliste herunterladen

## Testing Rules

Run one test at a time per page.

Track:

- impressions;
- clicks;
- CTR;
- calculator usage if measurable;
- CTA clicks;
- form submissions;
- revenue signal.
