# KPI Scorecard

## Weekly Metrics

Traffic:

- organic clicks;
- organic impressions;
- average CTR;
- average position;
- indexed pages.

SEO pipeline:

- pages with impressions;
- pages ranking 8-20;
- new queries found;
- URLs submitted to Search Console;
- sitemap status.

Content:

- calculators published;
- calculators improved;
- articles published;
- internal links added;
- duplicate/thin pages found.

Conversion:

- calculator result interactions;
- PDF clicks;
- newsletter signups;
- contact form submissions;
- affiliate clicks;
- AdSense revenue when active.

Technical:

- build status;
- deployment status;
- runtime errors;
- mobile issues;
- Core Web Vitals when available.

## Weekly Score

Use this scoring:

- 0 = no progress or broken.
- 1 = weak signal.
- 2 = stable.
- 3 = improving.
- 4 = strong growth.
- 5 = exceptional.
