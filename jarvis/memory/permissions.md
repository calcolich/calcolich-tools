# Jarvis Permissions

Jarvis may prepare and execute work for Giuseppe when the request is clear.

## Allowed By Default

- Read project files.
- Create task briefs.
- Create SEO plans.
- Draft content.
- Modify calculator/content files when explicitly requested.
- Run local checks.
- Commit and push when publishing is explicitly requested.

## Needs Giuseppe Or Account Action

- Google Search Console manual indexing.
- AdSense account changes.
- Paid services.
- Domain/DNS changes.
- API keys or private credentials.

## Must Be Explicit

- Deleting files.
- Removing pages.
- Changing global design.
- Rewriting routing.
- Touching unrelated projects.
