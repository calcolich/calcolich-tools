# Routines

These routines turn Jarvis from a chatbot into an operating assistant.

## Daily Morning Brief

Frequency: once per day.

Checklist:

- Check production homepage.
- Check last Vercel deployment status.
- Review Search Console impressions, clicks, CTR, and average position.
- Identify pages with impressions but low CTR.
- Identify pages ranking positions 8-20.
- Prepare three actions for the day.

Output:

- Traffic signal.
- Indexing signal.
- Revenue signal.
- Top 3 priorities.

## Search Console Queue

Frequency: after every new or updated priority page.

Checklist:

- Confirm URL returns status 200.
- Confirm canonical uses `https://www.calcolich.ch`.
- Confirm page is in sitemap.
- Confirm content is visible.
- Add URL to manual indexing queue.

## Content Expansion Loop

Frequency: weekly.

Checklist:

- Pick one calculator with impressions.
- Add or improve support article.
- Add internal links from calculator to article.
- Add internal links from article to calculator.
- Keep content specific to Switzerland when relevant.

## Monetization Review

Frequency: weekly after traffic starts.

Checklist:

- Review pages with traffic.
- Identify AdSense-safe placements.
- Identify affiliate opportunities.
- Identify lead magnet or PDF download opportunities.
- Do not add fake ad code.

## Release Routine

Frequency: every publishing session.

Checklist:

- Check changed files.
- Run lint, TypeScript, and build.
- Commit with clear English message.
- Push.
- Verify deployment.
- Verify affected production URLs.
